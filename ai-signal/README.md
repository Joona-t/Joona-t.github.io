# AI Signal

Public news reader at https://lovespark.love/ai-signal/.

Edit dated JSON in content/, then run `python3 ai-signal/scripts/render.py` from the repository root. Commit the changed content and generated HTML together. The latest dated edition becomes index.html. Assets and archive links are relative to this directory.

Up to five news items and three papers; caps are not quotas. Every item needs dates, an original HTTPS source, and evidence limitations. Paper fields: title, date, status (Preprint or Peer-reviewed), problem, contribution, evidence, limitation, implication, url, sourceLabel. Never publish evening check-ins or personal material. The initial edition is explicitly a Sep 16–21 catch-up, not a complete scheduled report.

Daily updates are not yet verified. Use the existing morning report schedule and handoff to this path's owning task; do not add another schedule. Only claim publication after GitHub Pages and a live content check succeed.
